# Django Blog API

## Демо

- Приложение: https://django-blog-test-2tvo.onrender.com/
- Документация API (Swagger): https://django-blog-test-2tvo.onrender.com/api/docs/


## О проекте

Это приложение для публикации постов с тегами и комментариями.
Пользователи могут создавать посты и комментировать свои и чужие записи.
Изменять и удалять чужие посты и комментарии нельзя.
При создании комментария подключённые пользователи получают уведомление через WebSocket.

## Связи между моделями

- `User` ↔ `Profile` — один к одному: у пользователя один профиль.
- `User` → `Post` — один ко многим: пользователь может написать несколько постов.
- `Post` → `Comment` — один ко многим: у поста может быть несколько комментариев.
- `User` → `Comment` — один ко многим: пользователь может написать несколько комментариев.
- `Post` ↔ `Tag` — многие ко многим: у поста может быть несколько тегов, а один тег может относиться к нескольким постам.

Обратную связь можно увидеть через список комментариев поста и список постов пользователя.

## Технологии

- Django — сервер и модели данных
- Django REST Framework — API
- Django Channels — WebSocket-уведомления
- Swagger/OpenAPI — документация API
- HTML, CSS, JavaScript — тестовый интерфейс

## Как запустить локально

Для запуска нужен Python 3.11. Команды ниже рассчитаны на PowerShell.

1. Создайте и активируйте виртуальное окружение:

   ```powershell
   py -3.11 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

2. Установите зависимости:

   ```powershell
   pip install -r requirements.txt
   ```

3. Создайте в корне проекта файл `.env`:

   ```env
   DJANGO_SECRET_KEY=вставьте_свой_секретный_ключ
   ```

4. Примените миграции:

   ```powershell
   python manage.py migrate
   ```

5. Создайте администратора:

   ```powershell
   python manage.py createsuperuser
   ```

6. Запустите сервер:

   ```powershell
   python manage.py runserver
   ```

После запуска откройте `http://127.0.0.1:8000/`. Админ-панель доступна по адресу `http://127.0.0.1:8000/admin/`.

Для проверки проекта запустите:

```powershell
python manage.py check
python manage.py test
```

## Запуск через Docker

1. Создайте в корне проекта файл `.env` с переменной `DJANGO_SECRET_KEY`.
2. Если файла `db.sqlite3` ещё нет, создайте его в PowerShell:

   ```powershell
   New-Item -ItemType File db.sqlite3
   ```
3. Соберите и запустите контейнер:

   ```powershell
   docker compose up --build
   ```

Приложение будет доступно по адресу http://localhost:8000/. При запуске контейнер применяет миграции. Локальная база `db.sqlite3` подключается к контейнеру через `compose.yaml`.

## API и документация

После локального запуска:

- Главная страница: `http://127.0.0.1:8000/`
- Админ-панель: `http://127.0.0.1:8000/admin/`
- Swagger UI: `http://127.0.0.1:8000/api/docs/`
- Схема OpenAPI: `http://127.0.0.1:8000/api/schema/`

Основные маршруты API:

| Адрес | Назначение |
| --- | --- |
| `/api/tags/` | Список и создание тегов |
| `/api/posts/` | Список и создание постов |
| `/api/comments/` | Список и создание комментариев |
| `/api/token/` | Получение JWT-токена по логину и паролю |
| `/api/token/refresh/` | Обновление access-токена |

Для изменения или удаления конкретного поста используется адрес с его ID, например `/api/posts/5/`. Создание и изменение данных требуют входа. Чужие посты и комментарии изменять или удалять нельзя.

## WebSocket

Подключение для уведомлений о новых комментариях:

```text
ws://127.0.0.1:8000/ws/comments/
```

После создания комментария сервер отправляет сообщение всем подключённым клиентам. Открытые страницы получают его без перезагрузки.
